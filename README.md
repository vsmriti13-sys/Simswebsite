# Smriti Vasistha · personal website

Built with Next.js. All the text, links and projects live in `src/content/site.ts`:
edit that file to update the site. Anything in [square brackets] is a placeholder.

- Photo: `public/smriti-vasistha.jpg`
- Project images: `public/projects/`
- Add a project: copy a block in the `projects` list in `src/content/site.ts`

Run locally with `npm install` then `npm run dev`, and open http://localhost:3000.
